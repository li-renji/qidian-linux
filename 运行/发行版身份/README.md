# 发行版身份快照（2026-09-25）

奇点OS 为发行版本体；Linux 内核为组件；Ubuntu 仅作组件来源（ID_LIKE=ubuntu 透明声明）。

- os-release:  PRETTY_NAME="奇点OS Linux 1.0 (基于 Ubuntu 组件构建)" ID=qidianos
- lsb-release: DISTRIB_ID=奇点OS / 1.0 / qidianos
- issue:       奇点OS Linux 1.0
- hostname:    qidian-os（/etc/hosts 127.0.1.1 qidian-os）
- grub:        GRUB_DISTRIBUTOR="奇点OS"
- mime:        qduser 默认文件管理器 = 奇点OS文件浏览器（inode/directory）

运行边界：/奇点OS 为主视图（qd_fm 打开即 /奇点OS）；Linux 底座（/）可见可入（侧边栏「🐧 Linux 底座」）。
