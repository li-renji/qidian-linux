## 项目结构

| 目录 | 内容 |
| --- | --- |
| `文档/` | 三份权威文档（开发文档 v1.15 / 包管理 v1.5 / AI 本地 Agent 调用 v1.4）+ 上一版本备份（v1.14/v1.4/v1.3）+ 从零构建方案 |
| `ai.qd/` | AI 子系统（最小独立系统 + chroot 隔离容器）：ai_service、ai.qdai、skills 仓库、容器内配置 |
| `init/` | 1 号进程源码（init.c：挂载虚拟文件系统 → exec boot.qds；devtmpfs EBUSY 回退修复） |
| `引导/` | 引导脚本 boot.qds v0.11（shell：设备节点 / chroot ai_service / 探活 / 转译桌面段 / 监督循环；按 QD_MODE 三分支执行） |
| `模块/` | 主系统模块区（.qd/.qds/.qdai 模块存放与热发现）；桌面.qd（desktop.c 转译桌面）/ 渲染器.qd / 包管理.qd / 用户态.qd |
| `模块引擎/` | module-engine 主系统引擎源码（扫描模块、`me>` 控制台、6801 内部链路、包管理子命令） |
| `scripts/` | Windows 侧驱动脚本（QEMU 启动器、构建入口等） |
| `仓库/` | 包仓库（rootfs 内 `/仓库/`：.qds 索引 + `实体/` 模块本体；本地拉取源；远程 `source: url` 待网络阶段 10） |

> 编译车间：Windows WSL Ubuntu 24.04（musl 交叉工具链）。构建 / 运行命令详见《开发文档 v1.14》§5、§9。
