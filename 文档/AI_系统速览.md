# 奇点OS 系统速览（AI 阅读版）

本文件是给 AI（意图 INTENT / 系统级 AI）快速认识本系统的入口文档。
完整规范见同目录《奇点OS_Linux版系统规范_v1.0.md》，AI 被问及系统架构时必须先读规范原文，不得凭速览作答。

## 一句话

奇点OS（Linux 魔改版）是运行在 Linux 之上、以 .qd/.qds/.qdai 为模块体系、以 AI.qd 为独立 AI 框架的操作系统级框架；AI 框架与系统框架双框架隔离。

## 双框架

| 框架 | 路径 | 进程（systemd） | 职责 |
| -- | -- | -- | -- |
| 系统框架 | /奇点OS/系统/ | qd-os.service | 界面（XFCE 深度定制）、模块、服务、用户程序 |
| AI 框架 | /奇点OS/AI.qd/ | ai-qd.service | 规则引擎、意图 Agent（INTENT）、记忆库、推理引擎、权限闸门 |

## 关键路径速查

* 意图 Agent：`AI.qd/intent_agent.qd/bin/module_main`（handle 主循环，返回 JSON 含 reply）
* 终端入口：`/usr/local/bin/qd-intent`
* 桌面板：`AI.qd/intent_agent.qd/share/intent_gui.py`
* 推理引擎：`AI.qd/推理引擎.qd/推理引擎.qds`（QDSS 容器；status/chat/config 三命令）
* 云端配置：`AI.qd/推理引擎.qd/etc/cloud.json`（含密钥，不入 git）
* 记忆库：`AI.qd/记忆库/`（日历简介层 + 详情层，防爆读取）
* 体检门禁：`系统/功能.qd/体检.qd/体检.qds`（C1-C9，每日 03:17 定时跑）
* 模块加载器：`运行/qd_loader.py`；QDSS 直接执行：`运行/qd-run.py <容器.qds> <命令> [参数]`

## AI 必须遵守的契约（摘要）

1. **诚实原则**：模型未就绪/未配置时如实报告，绝不假装可用。
2. **因果逻辑**：删除一个"起因"时，其衍生的所有"结果"必须级联删除（全系统最高治理原则，见规范 0.4）。
3. **权限**：读=眼睛令牌、写=笔令牌、删=橡皮令牌，由用户放权；AI 读到限制文件自动回避，不越权。
4. **记忆防爆**：日历简介全量可读，详情按 id 单点读取，单次 ≤20 条，超限列候选交用户确认。
5. **云端接入**：只需 API key；服务商预设见规范 5.8；key 不回显、不入库。
6. **错误码**：0=OK 1=契约/参数 2=依赖 3=权限 4=资源 5=内部；统一反馈 AI 框架。
7. **交付前自测**：Agent 交付任何产物前必须自己体验/运行一遍，通过才交付。
